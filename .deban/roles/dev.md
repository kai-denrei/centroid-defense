## Lessons
- A spawn config with `vx: 0` and a non-axially-spawned formation (line abreast across x) means most contacts will pass the rig with lateral offset, dealing no damage and creating no pressure — the wave is trivial. Always verify wave configs produce rig pressure on a no-strike playthrough. — from dead end on 2026-05-08
- Chrome `--virtual-time-budget` is unsuitable for verifying RAF-driven game loops; use real-time CDP-driven tests instead. — from dead end on 2026-05-08
- Headless Chrome `/json/list` returns extension and service-worker targets before the actual page; always `find(t => t.type === 'page')` when picking a CDP debug target. Wrong target = silent hang on Page.captureScreenshot. — from dead end on 2026-05-08
- `node --check` does not catch duplicate ES module imports; browser parsers do. Always run a real browser smoke (`Runtime.exceptionThrown` via CDP, or live page-load) on a fresh deploy before declaring it shipped. ES module `import` statements should also live at the top of the file — mid-file imports are spec-legal but parser-fragile. — from dead end on 2026-05-09
- For PWA cache freshness on rapidly-iterating apps, NetworkFirst HTML + `?v=X.Y.Z` query-bust on JS modules is sufficient. Adding `controllerchange → location.reload()` on top of `skipWaiting()` creates a race window where user input mid-deploy is eaten by the page navigation — bug is intermittent (only fires on the deploy-after-deploy reload) and "I tapped, nothing happened" is the user-visible symptom. — from dead end on 2026-05-09
- A flex container holding both a flex:1 child (variable width based on content) and a fixed-position UI element (e.g. an input control at one edge) must have its OWN width pinned, or the fixed UI shifts horizontally as the variable content reflows. — from dead end on 2026-05-09
- Adding a new view of the same board state doesn't add gameplay if the player's decisions don't change. If you find yourself adding cosmetic features TO the new view to make it feel more meaningful (drone tracers, contact-tracked ripples, etc.), that's the signal the view isn't carrying its weight — kill it and put the work into mechanics. — from dead end on 2026-05-10
- An autonomous unit + tap-to-vector reads as more "in control" than tap-to-summon because the agent is always on the field. The same number of taps, but the player has a continuous relationship with one persistent thing instead of a series of disposable instances. — from dead end on 2026-05-10
- When a defensive unit is invulnerable in some states but not others (e.g. drone safe on patrol, killable in flight), the inconsistency reads as a bug not a design — the creature that wanders to the edge should be able to swat the parked drone. Make collision rules state-independent unless there's a clear gameplay reason for asymmetry. — from dead end on 2026-05-10
